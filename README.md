# 소비노트

의류·잡화·주류처럼 경계하고 싶은 소비만 골라 기록하고, 비슷한 물건을 살 때 과거 구매가를 찾아보는 모바일 웹앱(PWA).

## 기능

- **빠른 기록**: 금액 · 통화 · 카테고리 · 사진만으로 저장. 나머지는 홈의 "정리 대기함"에서 나중에 채움
- **환율**: 외화는 구매일 환율로 자동 환산. 오프라인이면 마지막 환율을 쓰고, 그것도 없으면 온라인이 됐을 때 채움. 원화 금액은 카드 실청구액으로 고쳐 쓸 수 있음
- **찾아보기**: 상품명·브랜드·구매처 검색, 최저/평균/최근 단가 요약, 상세 입력 중 비슷한 구매 이력 표시
- **예산 게이지**: 카테고리별 월 예산 대비 지출 (선물·대리구매는 제외하고 따로 표시)
- **긴축 챌린지**: 설정한 달(기본 11월)에는 홈이 챌린지 화면으로 바뀜. 외식·식재·교통 등 생활비를 금액+카테고리만으로 기록하고, 총액 목표, 무지출일, 카테고리별 합계, 일별 달력, 작년 같은 기간 대비를 확인. 쇼핑 기록은 자동으로 '쇼핑'에 합산
- **구글 시트 동기화**: 기록이 시트에 쌓이고, 시트에서 고친 내용도 앱으로 돌아옴. 사진은 기기에만 저장

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 에 배포용 파일 생성
```

폰에서 쓰려면 `dist/`를 HTTPS로 서비스되는 곳(GitHub Pages, Cloudflare Pages, Vercel 등)에 올린 뒤,
안드로이드 크롬에서 열고 메뉴 → **홈 화면에 추가**를 누르면 앱처럼 설치됩니다.

## 구글 시트 동기화 설정

1. 구글 시트를 새로 하나 만듭니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 열고, 기본 코드를 지운 뒤 [apps-script/Code.gs](apps-script/Code.gs) 내용을 붙여 넣습니다.
3. 맨 위 `TOKEN = 'CHANGE_ME'`를 나만 아는 긴 문자열로 바꾸고 저장합니다.
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
5. 배포 후 나오는 웹 앱 URL(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
6. 앱의 **설정 → 구글 시트 동기화**에 URL과 토큰을 넣고 **지금 동기화**를 누릅니다.

이후에는 기록을 저장할 때와 앱을 열 때 자동으로 동기화됩니다.

- URL은 누구나 접근할 수 있는 주소이므로 토큰이 유일한 잠금장치입니다. 토큰을 공유하지 마세요.
- 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다.
- 시트에서 직접 고칠 때는 `수정시각`, `삭제`, `ID` 열은 건드리지 마세요(자동으로 채워집니다). 행을 지우는 대신 `삭제` 열에 1을 넣으면 앱에서도 사라집니다.
- 첫 동기화 때 `챌린지요약` 탭이 만들어집니다. B1의 날짜를 바꾸면 그 달의 카테고리별 합계를 보여줍니다.
- PC에서는 시트를 보거나, 같은 웹앱 주소를 브라우저로 열고 같은 URL·토큰을 넣으면 됩니다.

## 과거 긴축 챌린지 기록 가져오기

`import/convert.mjs`가 기존 달력형 시트(24.11, 25.11)를 가져오기용 JSON으로 바꿉니다. 결과 파일은 연도·주체별로 나뉘어 있으니, 앱의 **설정 → 기록 파일(JSON) 가져오기**에서 비교 기준으로 삼을 파일만 고르면 됩니다. 같은 파일을 다시 가져와도 중복되지 않습니다. (`import/` 폴더는 개인 지출 데이터라 git에서 제외했습니다.)

## 구조

- `src/db.ts` — IndexedDB(Dexie) 저장, 사진 축소
- `src/fx.ts` — 환율 조회와 캐시
- `src/sync.ts` — 시트 동기화 (변경분 올리기 → 전체 받기 → 수정시각이 최신인 쪽을 채택)
- `src/settings.ts` — 카테고리·예산·동기화 설정 (기기별 localStorage)
- `src/components/` — 화면 (`Challenge.tsx`가 챌린지 대시보드)
